# Version 41 — Science specialisations and distinct elective allocation

- Added Physics Nanophysics and Quantum Technologies specialisation baskets from official NUS Physics pages.
- Added an explicit distinct-course allocation check for seven Environmental Studies elective baskets, using bipartite matching. This is in addition to individual basket checks and the 88-unit total, which still count each course once.
- Existing Astrophysics and Pure Mathematics specialisations remain available.
- Specialisation residency, UROPS caps and parent-major overlap are **not fully enforced**. Those need course provenance and a more complete allocation model. The new specialisations remain partial.
- No changes to localStorage keys or existing student plans.
