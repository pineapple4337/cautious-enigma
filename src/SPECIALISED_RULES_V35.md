# Version 35 — Specialised FASS requirements (AY2025/26)

Research-based additions to the Version 34 programme information bank.

- Psychology: three level-4000 group checks; extra 2000/3000 elective; 5000 cap. Abnormal/Social/Applied basket remains provisional because current group mappings must be verified course by course.
- Japanese Studies: LAJ language stages, language-coded contributions, cap and exclusions; **JS-recognised external course list remains incomplete**. Waivers are not automatically applied.
- Southeast Asian Studies: single-track language minimum across LAB/LAM/LAT/LAV; advanced SE levels remain separate. Recognised non-SE basket not yet fully imported.
- Theatre and Performance Studies: three strand baskets, recognised-course cap, 5000 approval exclusion.
- Social Work: 8-unit field-practice CHS project check; excludes project courses from 60-unit SW major total.
- CNM: 8-unit CHS internship check; excludes NM3550C from the 60-unit major total. Alternative courses count by their actual units.
- Global Studies: advanced methodology basket; selected theme flagged for manual verification until a complete current theme mapping is encoded. Language is not silently counted in the 60-unit major.

All affected programmes remain marked partial. No user data storage keys were changed.
